# Contributing to the Arcapush registry

Thank you for adding to the registry. The category files are generated from [arcapush.com](https://arcapush.com) and are never edited by hand, so a build is added through Arcapush itself.

## Add a build with a pull request

1. Fork this repository and create a branch.
2. Copy `submissions/TEMPLATE.md` to `submissions/<your-build>.md` and fill it in. One build per pull request.
3. Open a pull request.

**What happens next:** your pull request becomes a **draft submission on Arcapush**. A maintainer creates the draft from your file and replies on the pull request with a link. Sign in to Arcapush with the GitHub account that opened the pull request, open the link, add your logo and screenshots, and submit. It is then **reviewed as usual**, by the same people and against the same bar as every other submission. The pull request is closed, not merged, with a link to the draft. Once the listing is approved, it appears here on the next weekly regeneration.

Opening a pull request does not list a build, skip review or move it up the queue.

## What a build needs

- a live primary URL,
- a real logo (not a placeholder),
- at least 1 screenshot,
- a description of 80 words or more.

The full rules are at [arcapush.com/docs#quality-bar](https://arcapush.com/docs#quality-bar).

## Do not include

- email addresses, phone numbers or any other private details. The file is public.
- referral or affiliate links.
- edits to `categories/` or `README.md`. They are regenerated and your change would be overwritten.

## Corrections and removals

To correct a listing, edit it on Arcapush from your dashboard; this registry picks up the change on the next regeneration. To have a listing removed, email support@arcapush.com from the address on the listing.
